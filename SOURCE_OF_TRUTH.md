# Project source of truth

Authority: explicit current user instruction → WORKFLOW_RULES.md → approved records scoped to the relevant series → creative standards and optional reference guides. A guide's date, “locked” heading or software default cannot override a higher instruction.

| Record | Owns |
| --- | --- |
| WORKFLOW_RULES.md | Current workflow constraints and phase reading list |
| PROJECT_RULES.md | Page 3 direction |
| project-state.json | Saved progress and unresolved steps |
| series/series-registry.json, SERIES_STATUS.md | Current series organization and paths |
| Series bible, continuity, approved episode script | That series' facts, approved lines and production intent |
| Provider handoffs and versioned schemas | Serialization and tool interfaces, within policy |
| Reference blueprints and PRODUCTION_LEARNING.md | Inspiration, observations and hypotheses |

Use PAGE_SETUP.md when settings are missing or a change is requested. Read RULES_AUDIT.md for superseded rules and the legacy validator gap.
